## 💻 一、电脑端如何启动使用？（小白 3 秒极速开启）

### 方法：双击运行启动脚本
1. 在项目文件夹中找到 **`server.py`** 文件。
2. 在电脑上运行该文件（或打开命令行输入）：
   ```bash
   python server.py
   ```
3. **软件会自动防冲突**：脚本会自动检查端口占用，自动选好空闲端口（如 `8085` 或 `8086`），并**自动为你打开浏览器页面**！

## ☁️ 二、手机电脑多端同步 & Cloudflare Pages 免费上线教程

想把网页放到网上，让手机电脑都能随时学？使用 **Cloudflare Pages**（完全免费，免服务器费用）！

### 第一步：将应用免费部署到网上
1. 打开 [Cloudflare 官网](https://dash.cloudflare.com/) 注册并登录账号。
2. 在左侧菜单找到 **Workers & Pages** ➔ 点击 **Create application** ➔ 选择 **Pages**。
3. 点击 **Upload assets (上传资源)**。
4. 在应用名字栏填入任意名称（例如：`my-english-app`）。
5. 把这个项目的整个文件夹直接**拖拽**到上传区域中，点击 **Deploy site**。
6. 完成！几秒钟后 Cloudflare 就会给你一个专属网址（例如 `https://my-english-app.pages.dev`）。

### 第二步：手机和电脑进度双向同步
1. 在电脑或手机打开上面的网址。
2. 点击网页右上方蓝色的 **“☁️ 多端同步设置”** 按钮。
3. 随意输入一个你自定的私密密钥（例如：`my-english-2026`）。
4. 在手机上也打开同一个网址，填入相同的密钥 `my-english-2026`，点击保存。
5. **搞定！** 以后不管在手机还是电脑上标记“已掌握”的单词，两边都会自动同步！

### 第三步：把网页放到手机桌面（当作 App 使用）
- **苹果 iPhone**：用 Safari 浏览器打开你的网址 ➔ 点击底部的“分享”按钮 ➔ 选择 **“添加到主屏幕”**。
- **安卓手机**：用 Chrome / Edge 浏览器打开网址 ➔ 点击右上角三个点 ➔ 选择 **“添加到主屏幕”** 或 **“安装应用”**。

## 🛠️ 常见问题解答 (FAQ)

### Q1: 发音声音不够大怎么办？
* 网页右上角有 **“音量增幅”** 滑块，直接往右拉到 **🔥 200% 或 300%**，声音就会爆破式放大！

### Q2: 麦克风无法跟读打分？
* 第一次使用跟读功能时，浏览器顶部会弹窗询问“是否允许使用麦克风”，请点击 **“允许”**。推荐使用 **Chrome** 或 **Edge** 浏览器。

### Q3: 想备份自己的学习进度怎么办？
* 点击 **“☁️ 多端同步设置”** ➔ 点击 **“导出本地 JSON 备份”** 即可把你的已掌握词库下载保存到本地文件。
